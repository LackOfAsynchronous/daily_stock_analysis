# 股票分析页交互式 K 线

股票报告摘要下方显示 Lightweight Charts 图表。大盘复盘报告不显示个股 K 线。

- 默认日 K，初始视窗约最近一年，可拖动查看接口返回的更早历史、滚轮缩放、十字光标查看 OHLC 和成交量。
- 日／周／月切换；周 K 按周一开始的交易日期分组，月 K 按自然月分组。开盘取首日、收盘取末日、高低取区间极值，成交量累加。任一天成交量缺失时，该周期不显示完整成交量；最新周／月可能尚未结束。
- MA5/10/20 可独立开关，按当前周期的收盘价计算；历史不足时不绘制对应均线。绿涨红跌。
- 使用 `/api/v1/stocks/{code}/history?period=daily&days=365`，复用服务端已有的数据源选择、密钥和回退策略。接口可能返回超出请求天数的历史；前端保留有效数据供平移查看，初始视窗仍约一年。
- 页面不直接访问第三方 API，不接触数据源密钥，也不调用 LLM。Massive 免费版的时效和额度限制仍适用，图表不承诺实时行情。
- 当前历史接口不返回实际提供商，不把来源臆断为 Massive。图表展示最新可用历史行情，并非所选报告生成时的快照；界面不显示额外的行情说明段落。
- 前端对同一股票合并并发请求，成功数据缓存十分钟、最多二十只；「刷新行情」绕过前端缓存，服务端缓存仍按既有策略生效。失败和空结果不缓存。
- 切换股票会忽略前一个股票迟到的响应；离开图表时销毁实例和尺寸监听。图表加载失败或无有效行情时提供刷新重试，不阻断报告阅读。

## 验证与回滚

前端执行 `npm run lint`、`npm run build`，以及 `stockCandles`、`stockHistory`、`StockCandlestickChart` 对应 Vitest 测试。实机检查日周月切换、均线开关、悬停、平移缩放、刷新与主题适配。

仅修改前端，无后端 API 契约、环境变量或数据库迁移。回滚此功能的提交并重新构建前端即可移除图表。安装库的单独依赖提交可保留。

图表保留 TradingView 归属标记和链接。本页为新功能中文说明，没有对应英文文档；图表本身支持中英文界面。
