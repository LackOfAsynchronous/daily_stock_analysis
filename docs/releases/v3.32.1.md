# v3.32.1·Special

这是 [LackOfAsynchronous/daily_stock_analysis](https://github.com/LackOfAsynchronous/daily_stock_analysis) 的定制发行版，基于原项目开发，汇总本 fork 初始基线 `ce364e457aab288863a5707e7b3df79786ad07f2` 之后的全部定制修改。不是原作者官方发行版。

## 下载与安装

| 设备 | 下载文件 |
| --- | --- |
| Apple Silicon Mac（M 系列） | `daily-stock-analysis-macos-arm64-v3.32.1.dmg` |
| Intel Mac | `daily-stock-analysis-macos-x64-v3.32.1.dmg` |
| Windows x64 安装版 | `daily-stock-analysis-windows-installer-v3.32.1.exe` |
| Windows x64 免安装版 | `daily-stock-analysis-windows-noinstall-v3.32.1.zip` |

macOS 打开 DMG 后将 App 拖入“应用程序”；Windows 运行安装程序，可选择安装目录。免安装 ZIP 请完整解压后启动。`latest.yml` 和 `.blockmap` 是 Windows 自动更新辅助文件，无需手动打开。`SHA256SUMS.txt` 提供下载文件校验值。

本发行版没有 Apple Developer 签名或公证，也没有 Windows 商业代码签名证书，首次启动可能出现系统验证提示。请确认下载来自本 Release；macOS 可按系统“隐私与安全性”中的允许打开流程处理。本版对 macOS App、内置 Python 和动态库执行 ad-hoc 临时签名与完整性检查；临时签名不提供 Apple 开发者身份认证或公证。

## 迄今全部定制修改

### 美股选股与行情数据

- 选股市场增加“美股”，提供美股双低、低波动质量、动量质量策略；从数据抓取、筛选到智能重排接通美股流程。
- 修正美股行情回退、盘中数据覆盖、技术数据与筹码缺失的诊断展示，区分正常回退、数据不支持与实际故障；不以隐藏告警伪装数据完整。
- 接入 Massive API，支持美股历史日线及由价量数据计算的估算成交成本分布；设置中可配置密钥和相关参数。
- 估算成交分布不代表真实账户持仓、机构筹码或逐笔资金流。数据覆盖、时效、请求额度取决于所用数据源和套餐；没有返回的数据仍显示缺失。

### AI 与本机 Codex

- 普通个股分析、选股智能重排、大盘复盘接入本机 Codex 生成后端。
- 问股以及多 Agent、Deep Research、图片识别等扩展调用路径接入 Codex，复用 DSA 的数据和工具能力。
- 增加 Codex 结构化输出处理、超时与失败反馈、能力状态检查和相关回归测试。
- 增加可选的本地投资上下文读取：运行数据目录下 `data/user_memory/USER_INVESTMENT_CONTEXT.md`，用于持久化个人偏好和历史研究背景。文件由用户自行管理，不视为最新行情或已验证持仓；不预设只研究 AI 行业。
- 本机 CLI 是调用安装在运行 DSA 设备上的工具，不代表模型离线运行；需要用户自行安装、登录并具备可用额度。API 接入仍需自行配置服务商密钥。
- 原生 Windows 的 Codex App Server 实验路径目前有限制；Windows 安装包可使用 API 模型，完整 WSL 后端按项目支持范围使用。安装包不附带 Codex CLI 或任何模型订阅。

### 模型、数据源、通知设置重整

- 将本机 CLI 和 API 服务商合并为一个“AI 模型配置”页面，按接入方式分区。
- API 服务商改为先选择下拉列表，再显示对应密钥、模型及高级配置；原有模型参数归入对应子区。
- 数据源改为提供商下拉选择及高级配置，减少无关字段同时出现。
- 通知渠道改为渠道下拉选择及高级设置，保留渠道测试入口，包括 Telegram。
- 移除配置分类右侧的字段数量徽章。
- 分类顺序调整为：基础设置、AI 模型配置、Agent 设置、数据源、通知渠道、定时任务、回测配置、系统设置。
- 将定时任务从系统设置独立出来，集中管理运行时间与状态。
- 将主题和语言入口从主导航移动到“设置 → 系统设置”；外观、语言分开，分别使用下拉列表并即时生效。

### 股票查询与交互式 K 线

- 首页搜索改为“先查询行情，再选择 AI 分析”：输入代码或选择搜索建议即可显示基本行情和 K 线，搜索本身不调用 AI。
- 基本行情展示价格、涨跌、今开、昨收、最高、最低、成交量、成交额和振幅；缺失字段显示“—”，报价与 K 线独立加载并可刷新。
- 加入 TradingView Lightweight Charts 交互式 K 线，支持拖动平移、滚轮缩放、十字光标、日/周/月周期、成交量和 MA5/10/20 开关。
- 历史行情复用已配置数据源，并增加前端请求合并和缓存；周/月 K 由日线聚合。
- 右上角先显示“AI 分析”；点击后提交分析任务，完成后显示原有完整报告，按钮变为“追问 AI”。
- 查询新股票时隐藏上一只股票的 AI 内容；其他股票后台任务完成不会替代当前查询视图。修复跨股票分析完成后没有自动打开新报告的问题。
- 删除图表下方冗长的历史行情说明段落，保留图表操作提示及 TradingView 授权署名。

### 主导航与布局

- 从主导航移除“持仓”入口，保留既有底层数据与兼容能力。
- 桌面侧栏收窄至 128px，菜单填满内宽，DSA 品牌与菜单水平居中，减少右侧多余留白；移动端保留抽屉导航。

### 发行与更新

- 提供 macOS arm64、macOS x64、Windows x64 安装包及 Windows 免安装包。
- 更新检查与 Windows 更新元数据指向本 fork 的 Releases，避免被原项目的后续版本覆盖定制功能。
- 提供源代码、完整修改记录及下载校验值，可从同一 Git 标签复现构建。Release 先建为草稿，三个平台全部构建成功后再发布。
- 发布前同步旧界面测试文案、修正依赖固定日期的信号时间线测试，并将更新按钮提示统一为应用 Tooltip。
- 修复打包工具移除构建配置后更新地址读取导致的启动问题；每个平台打包时检查实际 ASAR 中的版本与更新仓库元数据。
- 修复 macOS 完全未签名导致应用被系统终止、Python 动态库无法加载的问题；逐一签名 Mach-O 文件，再签名 App，并检查最终 DMG。

## 配置和升级说明

- **包内不含个人 API Key、Telegram Token / Chat ID、登录凭据、分析数据库、个人投资记忆或私有配置。** 用户需自行配置；Telegram 机器人创建和个人配置不属于共享发行包内容。
- 安装前可在系统设置导出配置备份。新版继续使用 DSA 原有用户数据目录，替换 App 不等于清空用户数据。旧包内部的历史 `.env` 如未迁移，应按桌面打包文档处理。
- Massive、模型服务、搜索服务和通知服务的费用及权限由各服务商决定；应用开源不代表第三方服务免费。
- 本次没有重新设计原有回测和 AI 建议信号的计算规则。
