# 首页股票查询与 AI 分析

搜索框输入股票代码，或选择名称搜索建议，再点击“查询”或按回车。页面先显示基本行情和交互式 K 线，查询本身不调用 AI。即使有该股票的历史报告，也先展示行情视图。

基本行情复用已配置数据源的报价接口，包含价格、涨跌额、涨跌幅、今开、昨收、最高、最低、成交量、成交额，以及由高低价和昨收计算的振幅。未返回的字段显示“—”。报价和历史 K 线分别加载，报价失败可单独刷新。数据的延迟和覆盖范围取决于数据源，不保证实时；接口更新时间是抓取时间，不作为交易所报价时间展示。成交量沿用报价接口的股数口径。

行情视图右上角的“AI 分析”沿用已配置的模型、策略和推送通知选项，提交新的分析任务。等待期间仍可查看行情，或查询另一只股票。只有当前股票的新报告就绪后才展示完整分析页面，右上角显示“追问 AI”。上一份报告和其他股票后台完成的报告不会替代正在查看的行情。

左侧历史记录仍可直接打开完整旧报告；选股等页面显式要求自动分析的入口保留原行为。K 线周期、成交量和均线操作见 [交互式图表](interactive-charts.md)。本专题无英文对应文档。

## 验证与回滚

运行前端 `npm run lint`、`npm run build` 以及 HomePage、stockCandles、stockHistory、StockCandlestickChart 的 Vitest 测试。首页回归覆盖查询不调用 AI、报价失败独立重试、旧报告隐藏、当前股票报告切换和跨股票任务完成。实机验证搜索与回车查询、K 线展示、AI 分析提交和报告完成后的追问按钮。

变更只涉及前端，不迁移数据库和密钥。回滚此功能提交并重新构建前端即可恢复搜索直接分析的行为。行情接口和 AI 分析接口保持原契约。
